# IQ Scoring conformance examples

[`iq-scoring-v2.1.json`](iq-scoring-v2.1.json) contains informative, machine-readable examples for specification version 2.1. The normative requirements remain in [IQ-Scoring-Spec.md](../IQ-Scoring-Spec.md).

Each case contains the relevant configuration, extraction output, and expected scores or decision. Numeric comparisons should use the `absolute_tolerance` declared by the vector file.

The vector format is an interchange format for conformance testing. It is not a required implementation API.
